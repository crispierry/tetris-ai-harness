The production credential location is fixed at `~/.config/tetris-ai-harness/openai.env`; no command-line key value or environment-key lookup is supported. The existing file must be a single-link regular owner file, mode0600, in a real owner directory mode0700, with no symlink ancestors. Both configuration and credential readers validate size, ownership and permissions, open with no-follow, compare opened descriptor identity with the checked path/parent, and recheck after reading. The key file is bounded at1024bytes and must contain exactly one bare `OPENAI_API_KEY=` assignment with16–512ASCII letters/digits/underscore/hyphen and an optional final LF. Quotes, comments, duplicate assignments, CRLF, shell commands and interpolation reject. Parsing never evaluates or sources text. These strict rules may reject an existing incompatible file; they never rewrite it or change permissions.

The reader passes the value directly into the service closure. It never exports it to `process.env`, argv, browser assets, status, receipts, ledger, logs or a second credential store. Read buffers are cleared and descriptors close; JavaScript strings cannot promise cryptographic memory erasure. Loader/path injection is available only through exported helper functions for disposable private dummy tests; the production entrypoint supplies no override. Errors are sanitized. No key is created, discovered, provisioned or read by the source tests.

## Qualification and reservation

`owner-qualified-decisions-live-v2` permits only the fixed POST Decisions issuer and requested `gpt-6-luna`, request schema `decisions-create-fixed-1`, body bound1048576bytes and response bound65536bytes. These byte bounds protect parsing; they are not token bounds. The request schema has no invented output-token or framing limit, cache/tier override or Responses field.

The qualification requires an explicit positive `totalBillableInputCeiling` and `reservationTokens` at least that large. `ceilingEvidence` contains exactly `status`, `model`, `endpoint`, `requestSchema`, `totalBillableInputCeiling`, `includesQuestionsAndFraming`, `sourceURL`, `checkedAt` and `validUntil`. Times are integer Unix milliseconds. The evidence must explicitly be qualified, include questions/framing, match the exact model/issuer/schema/ceiling, use an accepted official Decisions/model source URL, be currently valid and expire no later than24hours after its checked time. That freshness limit is a local fail-closed policy, not a provider guarantee. Merely supplying an accepted URL is insufficient real-world qualification. Missing, HOLD, stale, unknown or mismatched evidence cannot enable the service. Evidence is cloned immutably and rechecked on status/admission and immediately before dispatch. An observed input usage exceeding the asserted ceiling disables further live work and retains the uncertain reservation.

Exact pricing fields are `inputMicrosPerMillion:100000`, `cacheWriteMicrosPerMillion:125000`, `cacheTTL:'30m'`, `longContextMultiplier:2`, `regionalNumerator:11`, `regionalDenominator:10`, `outputBilling:'free'`, and `outputMicrosPerMillion:0`. This pins the supplied endpoint-specific30m-only/default cache contract. Unknown fields, positive output price, fabricated output limit, unsupported cache lifetime or reduced multipliers reject. Schema/pricing/cache changes require fresh qualification; no automatic alternative exists.

`reservationMicros` is the exact integer ceiling of `reservationTokens × (100000 + 125000) × 2 × 11 / (10 × 1000000)`, computed with integer arithmetic. Reserving full normal input plus full cache-write cost is deliberately conservative. The policy must match the qualification reservation, have enough input/cost capacity for one reservation, keep aggregate maximum input tokens no higher than reservationTokens×maxAttempts, and keep maximum estimated cost at or below10000000microUSD. The initial pilot has at most20attempts and expires no later than its explicit immutable `pilotStartedAt` plus300000ms. No renewal/reset of that timestamp or policy expiry occurs on restart.

Every lane/tab/epoch shares the existing durable aggregate. Reserve precedes dispatch-intent; aborted, failed or uncertain work does not refund, retry or fall back. Existing drain behavior retains the lock while upstream work remains unsettled.
