# Bounded visible-piece lookahead

`public/lookahead.mjs` is browser-safe pure game/search code: no DOM, Node imports, credentials or transport. It exports `evaluateLookahead`, `createLookaheadProvider`, and local/mock leaf evaluators. Existing Controller and UI code are unchanged. A provider still returns exactly `requestId`, `stateRevision`, `selectedCandidateId`; detailed search evidence is separate in `lastSearch` and `lastReceipt`.

Depth1 evaluates the supplied current-placement canonical afterstates. Depth2 expands one additional known piece through canonical reachable paths and simulation. There is no deeper search, hold, spin state, sprint, realtime policy or unseen-future expectation. The simulated internal state is reconstructed only from the public afterstate's board, active pose, counters and four remaining known queue entries. A fixed isolated synthetic randomizer fills engine bookkeeping internally. It cannot change the known next spawn or the evaluated board. Root evidence is rebuilt through the observation allowlist. Child evidence uses an explicit three-preview limit and verifies it equals the original remaining three; it never uses the four-preview `candidateEvidence` helper for a child. No synthetic state, seed/RNG or generated queue entries are returned to an evaluator or report.

Every leaf evaluator receives full post-clear occupancy, active pose, known preview, features, placed cells, line/score deltas and terminal reason. Raw board/features and scalar value remain distinct. The default versioned heuristic is −5×holes −0.5×aggregate height −0.2×maximum height −0.2×bumpiness +8×cleared lines, with −1,000,000 for terminal leaves. Leaf values must be finite numbers within [−1,000,000,1,000,000]. Custom local/mock evaluators must declare a bounded policy/rubric and version. Live/model evaluators are unsupported. These values are not win probabilities, calibrated confidence or evidence of model quality.

Depth1 uses that leaf value directly. Nonterminal depth2 roots use8×root cleared lines + discount×best child leaf value; default discount0.9. Terminal roots stop immediately at their terminal leaf. Equal values retain original root order, then canonical child order. There is no pruning or cache. Reports retain every root score and its best leaf with full occupancy; all child leaves are evaluated with full occupancy, while losing child leaves are discarded to bound report size. Cache is explicitly off; its documented future key would include rules, complete known state, feature/evaluator/objective and assistance versions.

Default limits:4000 placement nodes,4000 evaluator calls,500ms search time,2MiB report output, depth1. Maximums:4000 nodes/calls,5000ms time,4MiB output, depth2. A node is a supplied root placement or a simulated child placement; canonical reachability separately retains its800-pose/4000-transition limits. Search time is also bounded by the packet's decision deadline. Calls are local/mock leaf evaluations, not model requests; live model-call/spend caps remain zero. Configuration/input/caps are checked before work and after synchronous/evaluator returns; chunk yields permit cancellation. JavaScript cannot preempt arbitrary synchronous caller code, so an expired return is discarded. Evaluator functions are trusted executable inputs, not a network sandbox.

Node/call/time/output exhaustion, cancellation, invalid leaf values and evaluator errors fail the decision with no selected root or partial winner. Failed reports exclude partial root rankings. Evaluator scopes abort on completion/failure and clear timers/listeners; caller signals are not aborted. Reset→Step may immediately replace cancelled work; old cleanup/results cannot replace newer receipts. Progress reports distinguish offered/completed roots, enumerated children, visited nodes, evaluated leaves/calls, zero pruned branches, elapsed overhead and complete/failed status.

Run manifests retain the named depth/search/evaluator policy in player configuration. Depth1-versus-depth2 experiments are algorithm/assistance comparisons, not equal-assistance provider-quality tests. Any later Astra-versus-Decisions/Jev comparison must use the same external search and evaluator assistance for both competitors and retain a direct track. Saved-decision replay verifies chosen canonical transitions, not recomputation of search timing or live model responses.

Bounded offline paired runs report actual score/lines/survival, latency/overhead, failures, caps and sample counts; small capped examples do not establish an improvement or winner. P8-011 owns rendered settings/search summaries and full combined UI acceptance. Its labels must show depth/tier, limits, completed versus exhausted, explored/pruned counts, evaluator rubric and measured overhead. P8-006 enlarged-text acceptance remains separate; tool access/detection failure is not proof of a locked host.
